# ST7529：补齐 LI/CI 输出地址映射

日期：2026-09-06。补齐 guest 已能设置、但原 LCD 模型没有使用的行/列反向参数。
这是控制器功能实现；不将它解释成此前菜单损坏的原因，也不宣称 LCD 全部完成。

## 依据与实现边界

[ST7529 v1.8 手册](../tmp/pdfs/ST7529.pdf) 第 25 页 RAM 映射表、
第 25–26 页 7.3.2/7.3.3、第 41 页 DATSDR 定义及第 42–43 页方向图。
相关整页已按 PDF 技能目视核对。文件 SHA-256：
`8565fc8d1f917f89667d1ac3439699888f669ec0ac774438d852848371d02031`。

- `LI`：反转全部 160 行的 RAM 到公共电极输出对应关系。
- `CI`：反转全部 85 个列组的 RAM 到段电极输出对应关系，每组三个像素不因此互换。
- `C/L`：决定 MPU 先推进列组还是行，地址仍从设置的起点递增至终点。
- `CLR`：控制每组三个像素的总线排列，独立于 CI。
- CASET/LASET 是 MPU 读写窗口，不是反向操作的轴或显示裁剪边界。

因此不能反转 Web 的 240×120 图像代替此功能。CI 下，原来不可见的 RAM 列组 84
应出现在最左侧；按可见的 80 组反转、或直接倒排 255 个独立像素都会产生错误。

修改 [QEMU LCD 模型](../qemu-dmcu/hw/dmcu/np560.c) 的实际输出坐标查找：
光栅与状态电极共用 LI/CI 映射；GRAM 存储和 MPU 读写计数器不变。
`lcd-frame` 读取当前设置下的显示输出，`lcd-gram-frame` 仍是逻辑 RAM 观察视图。
切换 DATSDR 即可改变输出方向，不需要重写像素。

本机固定玻璃接线和 COMSCN 的现有实现未更改；其依据仍是先前的固件/图像反推，
没有新增真机接线测量。状态电极仅输出设备内存对应电平，不按图标名或电池值合成。
该次扫描修复未覆盖部分显示、滚动、RMW、其它命令/总线宽度及完整 COM 时序。
后续已补合法连续范围的 [部分显示与正常状态位](np560_lcd_partial_display.md)；
以下构建与证据仍专指 LI/CI 修复。
