## 原厂代码决定按键含义

三张 V3.80 键表的矩阵位置 M55 均产生 `00B0`。以下地址使用 VMA03；
静态 PRG 源地址为运行地址加 `1D0000`，文件偏移为运行地址减 `030000`。

1. `20:2F62` 比较 B0，进入 `20:3102..3134`。它保存当前应用状态到
   `51:2AA2`，将 `51:2AAA` 设为 FF，并设置事件处理标志。
2. 主循环 `22:527C..5280` 对 FF 进入 `22:52DC`。
3. `22:52DC..5302` 判断菜单类别 `51:2AA0`：若为 1，则写 0；否则写 1。
   随后清选择项 `51:2A7C`，设置刷新标志 `51:2AC0`。

实际画面将类别 0 对应到开始菜单、类别 1 对应到学习菜单。因此这不是无条件
“打开开始菜单”的宿主命令。按键发生在哪个应用、前一次事件是否结束、当时类别
是什么，都影响结果。其它应用的退出路径还可能自行处理 B0，不能把上面的主循环
概括成所有窗口统一需要按两次。

上轮曾从类别 0 或类别 5 再按 B0，回到类别 1 后仍按旧路线确认，因而进入学习应用。
这个解释有原厂分支与当时 `MENU_PATH_WRITES` 支持；不需要更改矩阵映射、自动追加按键
或直接修改菜单类别来“修好导航”。旧记录见 [声音状态 RAM](np560_audio_state_ram.md)。
