     Core Technologies
     
            
    CYBIT has created a wide selection of proprietary speech and audio compression, recognition, synthesis and transmission technologies. These technologies are offered as follows:
       Licensing
      Core technologies offered in ANSI C code, 16-bit fixed-point C code, TI C54x and other DSP code, and Windows 95/NT DLL (dynamic linking libraries).
       
       Application Solution Chip & Module (ASC/ASM)
      Core Technologies offered in chip/module for hardware integration.
       
       Demos
      MS .WAV files to demonstrate speech/audio quality at various compression rates and channel BER.

    Please contact sales@cybit.com
    DOS evaluation .exe codes for all coders.

     Application of the core technologies include:
     
    Digital Storage
    Voice/music recording: recorders, organizers, messaging center, telephone answering devices.
    Voice/music playback: audio books, audio guide, voice response systems.
    Voice/audio database: 911 records, transaction records, legal/medical/judicial records.
     
    Digital Transmission
    Network transmission: Internet, Intranet, computer telephony, VoIP.
    Wireless communications: satellite, cordless, cellular, paging, packet voice, special-cast.
    Voice/audio over noisy channels: frame loss, wireless bit errors, wired network imperfection.
     
    Voice Access
    Voice command: web/appliance access for portable, vehicular, industrial, home applications.
    Voice playback: E-dictionary, E-manual, auto attendant system, integrated messaging.
    Voice interaction: educational and disabled aids, electronic games, database access/retrieval.
