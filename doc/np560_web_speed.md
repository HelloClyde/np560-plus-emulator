## 尚未解决

精简观察仍约为实时的四分之一（本次冷启动窗口），人工短按仍可能漏扫。
代码检查确认当前 icount 路径每块只有一条指令，并且每条仍调用大型 C 解释执行 helper；
时钟记账也逐指令执行。这些是后续必须剖析的执行成本，尚无采样占比证据，
不能把它们分别宣称为已量化的主要热点。
不得直接放宽多指令块：此前存在中途退出后多计指令的明确反例。

再验证稳态实时倍率及人工短按；当前没有达到速度问题的完成条件。
