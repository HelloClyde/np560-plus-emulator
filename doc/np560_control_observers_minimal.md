# 精简控制观察实验与音频执行成本

日期：2026-09-08。为解决 M2 续填延迟而作的执行路径分离，不改变 HLE 解码算法、
CPU 指令语义、PLL、IRQ 优先级或 DTU/DAC 请求。不是完整模拟器或实时音频验收。

## 范围和默认值

QOM `control-observers-minimal` **默认 false**，现有运行方式保持完整观察器。
实验脚本显式传 `--minimal-control-observers`，在首次 `cont` 前启用；用户 Web 未替换。

- true 时跳过约 9000 行历史 `trace_control_transfer` 观察路径。
- 保留原有非法控制转移检查，复用同一个 `trace_invalid_control`，完整记录首个坏地址、
  GPR、DS、SP/FP、栈/帧等；未关闭 ROM 缺失、unsupported、IREP 或 IRQ 栈检查。
- 保留基础调用/返回环，在首个非法转移时冻结。历史菜单等特定地址的冻结策略不再运行，
  因而不能称两种模式的全部日志相同。
- 保留 `20:2E9E` 的原始前台按键 ACK 槽 85 及采样字段，避免省掉 Web 的只读事件确认。
  modal ACK 位于另一个执行观察点，本次没有移除。
- 其余 pre-execution、数据总线观察器仍在。这不是“所有调试功能关闭”或原生 TCG 实现。
- CPU 运行时拒绝切换；实验选项随 RESET 和 CPU pre-load 配置恢复。
  拒绝与旧广泛 `rom-hle`/`hle-ui` 同用；登记的 MP3 HLE v4 不受此拒绝条件影响。
- `cpu-state` 标明 `CONTROL_OBSERVERS=full/minimal`，实验报告记录开关。
  精简模式下未采集的历史字段可能为零或旧值，**不能用它们证明 guest 没执行某段代码**。

这是显式实验选项，未改为默认，也不声称所有诊断依赖已经形式化证明等价。
若未来作为常用运行模式，还需核对其余应用与输入路径、诊断依赖和生命周期。

## 源码核对

`scripts/audit_np560_control_observer.py` 用 pycparser 解析实际函数，递归收集其本地
trace/snapshot/reset helper 的字段写入、memcpy/memset 目标、输出指针和外部调用边界。
此工具仅为语法树清单，不是类型检查、全程序别名分析或“无副作用”的自动证明。

- 初始清单 `tmp/np560-control-observer-audit-20260908-v1.json`：24 个函数、1862 个写入字段。
- 分离后清单 `...-v2.json`：26 个函数，字段集合仍为 1862；与当前 CPU VMState 中
  保存的寄存器/IRQ/循环/物理输入字段交集为空。不是证明 VMState 本身已覆盖所有整机状态。
- 本地 helper 输出指针为诊断快照、计数、局部 mask/valid；内存复制目标为诊断数组。
  其余边界包括内存/代码读取、地址计算、日志和标准内存操作；没有从这里调用 guest 存储函数。
- 特别保留两项会被其它层消费的状态：`invalid_control_valid` 等故障快照，以及前台按键 ACK。
  不仅依据函数名或注释就整体关掉它。

## 整机验证

使用原厂 PRG/UPD、相同 tone NAND、HLE v4 ROM，保持正常时钟与物理选曲路径，
以 DTU 完成/受理/重装和实际 DAC 录音复核。两轮均已正常退出，使用上述同一
`7b485585…` 构建、12 次播放观察和 60 秒墙钟录音上限；没有并行 QEMU 实验，
没有 GDB、运行时 RAM 注入或 NAND 保存。原厂选择文件和开始播放的物理按键路径均通过。

两轮均去重取得 768 个 refill 事件，左路观察 385、右路 383；同一筛选口径为
已受理、COUNT=576、完成到重装小于 20 ms。完整模式筛选左 383 / 右 358，

以上分位数排除了长的曲目交接，不能称作所有重装延迟。
完整录音末端另有 0.164833 秒零输出，因截断未列入完整交接范围。

同构建 A/B 显示这条观察路径的成本确实影响续填和曲目切换；左路中位数本轮降低约 19%。
但仅为每种模式各一轮整机观察，不能推出跨主机或长期固定加速比例。
探针在快照期间暂停 CPU；墙钟采集长度与设备录音长度不同，累计 HLE 计数的观察范围
也更长，不能相除得到解码吞吐，更不能把 30.141/26.685 当作正常 Web 实时速度。

437.578 / 436.069 / 437.750 Hz。仍未保持 440 Hz，双声道也未逐帧对齐。
